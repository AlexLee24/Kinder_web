## 一、隱私權政策

最後更新：2026-11-27

Kinder（kinder.astro.ncu.edu.tw，以下稱「本網站」）由國立中央大學天文研究所 GREAT Lab（以下稱「我們」）維運，用於暫現天體（transient）的追蹤、觀測規劃與研究資料整理。我們依中華民國《個人資料保護法》蒐集、處理及利用你的個人資料，本政策說明我們收集哪些資料、為什麼收集、存放多久，以及你有哪些權利。

### 1. 我們蒐集的資料

**(1) 帳號資料**
- 使用 Google 登入時：Google 提供的電子郵件、姓名與大頭貼網址。我們不會取得你的 Google 密碼。
- 使用帳號密碼登入時（由管理員建立）：使用者名稱與經過雜湊處理的密碼，我們不保存明文密碼。
- 你的角色（訪客、使用者、成員、管理員）與所屬群組，由管理員設定，用來決定你能看到哪些頁面與資料。

**(2) 你在網站上產生的內容**
- 上傳的光譜、測光資料、評論、標記、觀測紀錄、觀測請求（Trigger）、行事曆項目與文件。
- 這些內容會連同你的帳號一起記錄，讓其他有權限的使用者知道是誰提供的。

**(3) 偏好設定與通知**
- 介面設定（背景、配色等）：登入後存在伺服器；未登入時只存在你的瀏覽器（localStorage）。
- 如果你開啟推播通知：瀏覽器提供的推播訂閱端點與金鑰，關閉後即刪除。
- 如果你建立 API 金鑰或行事曆訂閱連結：金鑰與連結代碼。

**(4) 系統紀錄**
- 為了安全與除錯，伺服器會記錄請求時間、網址、IP 位址、帳號與錯誤訊息。這些紀錄只有管理員能查看，保存期間為 3 天。

**(5) Cookie**
- 本網站只使用必要的登入 Cookie（工作階段），沒有廣告或追蹤用 Cookie，也沒有使用 Google Analytics 等第三方分析工具。
- 登入狀態最長維持 30 天；14 天沒有使用會自動登出。
- 安裝成 App（PWA）時，瀏覽器會快取網站檔案以便離線開啟。

### 2. 我們如何使用這些資料

- 讓你登入、辨識身分，並依角色與群組控制存取權限。
- 顯示資料的提供者，維持研究紀錄的可追溯性。
- 寄送你要求的通知（推播、電子郵件、實驗室內部通訊軟體），例如新目標警報或值班提醒。
- 維護網站安全、排除錯誤、防止濫用。

我們**不會**出售、出租你的個人資料，也不會用於廣告。

### 3. 第三方服務

使用本網站時，部分功能會連到以下外部服務：

- **Google**：Google 帳號登入。
- **網頁資源**：Google Fonts、Plotly 等函式庫的 CDN。
- **觀測站與合作單位**：送出觀測請求時，目標與觀測設定會寄給鹿林天文台或相關合作者。

這些服務各有自己的隱私權政策，我們無法控制其處理方式。

### 4. 資料存放與保存期間

- 資料存放在 GREAT Lab 管理、位於國立中央大學的伺服器與備份儲存裝置。
- 帳號資料在帳號存在期間保存；帳號刪除後，個人資料會在 3 天內刪除或去識別化。
- 你上傳的科學資料（光譜、測光、觀測紀錄）屬於研究紀錄的一部分，帳號刪除後可能會保留，並繼續標示你的名稱為提供者。

### 5. 你的權利

依《個人資料保護法》第 3 條，你可以：
- 查詢或請求閱覽你的個人資料；
- 請求製給複製本；
- 請求補充或更正；
- 請求停止蒐集、處理或利用；
- 請求刪除。

部分資料可以直接在「Settings」頁面修改；其他請求請寄信到 kinder [at] astro.ncu.edu.tw，我們會在 30 天內回覆。若你拒絕提供必要的帳號資料，將無法登入使用需要權限的功能。

### 6. 資料安全

我們採取合理的安全措施，包括 HTTPS 加密連線、密碼雜湊、登入工作階段限制、權限分級與管理員操作紀錄。但沒有任何網路服務能保證絕對安全；若發生個資外洩，我們會依法通知受影響的使用者。

### 7. 未成年人

本網站以研究人員與學生為對象。未滿 18 歲者請在法定代理人同意下使用。

### 8. 政策更新

本政策修改時，我們會在本頁更新日期；重大變更會在網站上公告或通知已登入的使用者。

## 二、服務條款

最後更新：2026-11-27

歡迎使用 Kinder。使用本網站即表示你同意以下條款；如果不同意，請不要使用本網站。

### 1. 服務內容

Kinder 提供暫現天體資料瀏覽（Marshal）、觀測規劃工具、天文計算工具，以及供 GREAT Lab 成員使用的研究功能（Pipeline、DETECT、Trigger 等）。部分功能需要登入，或需要管理員授予特定角色或群組才能使用。

### 2. 帳號

- 你應提供正確的資料，並妥善保管帳號、密碼與 API 金鑰，不得借給他人使用。
- 透過你的帳號進行的操作，視為你本人的行為。
- 發現帳號遭到盜用時，請立即通知管理員。
- 管理員可以依研究需要調整你的角色與權限。

### 3. 使用規範

使用本網站時，你同意不會：
- 嘗試未經授權存取其他帳號、頁面或資料；
- 干擾或破壞網站運作，例如大量自動請求、攻擊或掃描漏洞；
- 使用 API 時超出合理用量，或規避存取限制；
- 上傳惡意程式、不實資料，或侵害他人權利的內容；
- 將未公開的資料用於本條款允許以外的用途。

### 4. 資料與智慧財產

- **公開資料**：來自 TNS、各巡天計畫等外部來源的資料，其權利屬於原始提供者，引用時請依各來源的規定致謝。
- **你上傳的資料**：你保有原有的權利，但同意本網站為了提供服務而儲存、顯示，並依權限設定分享給其他使用者。
- **未公開資料**：GREAT Lab 及合作計畫中尚未發表的資料（例如未公開的觀測、測光、光譜與分析結果），僅供有權限的使用者於研究合作範圍內使用；未經資料提供者或 GREAT Lab 同意，不得轉傳、公開或用於發表。
- 本網站的程式、介面設計與文件屬於 GREAT Lab，保留所有權利，未以開放原始碼授權釋出。

### 5. 發表與致謝

使用本網站取得的資料或分析結果進行發表時，請依合作規範列名或致謝 GREAT Lab 與 Kinder。

### 6. 免責聲明

- 本網站的資料與計算結果（包括測光、紅移、可見性、曝光時間估計等）按「現狀」提供，僅供研究參考，我們不保證其正確、完整或即時。
- 本網站可能因維護、故障或外部服務中斷而暫停，我們不對因此造成的損失負責。
- 外部網站連結的內容由各該網站負責。

### 7. 停權與終止

違反本條款時，管理員可以不經通知暫停或終止你的帳號，並移除相關內容。你可以隨時聯絡我們刪除帳號。

### 8. 條款修改

我們可能會修改本條款，修改後會在本頁更新日期；你在修改後繼續使用本網站，即視為同意修改後的條款。

### 9. 準據法

本條款以中華民國法律為準據法。
