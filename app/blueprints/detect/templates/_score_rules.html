How the score is built start at 0, add every rule that applies
Vetoes (known things)
  • −10 Galactic type on TNS (CV, VarStar, Nova, M dwarf, YSO, WR, microlensing)
  • −10 AGN / QSO / blazar / NLS1 on TNS, or nuclear on an AGN host
  • −6 Already classified (has a spectrum)
  • −3 Spectroscopic star at the position (Star?)
Interest
  • +3 DESI host found (rule v1) +2 more if still unclassified · +1 if the host is tentative
  • +3 Luminous: M ≤ −20 +1 more if M ≤ −21 (SLSN?)
  • +2 TDE?: nuclear (≤ 1″ from the host centre), host not an AGN, not Galactic
  • +3 Too-bright: M ≤ −20.3 (Ia peak −19.3 − 1) at z ≥ 0.15 → lensing candidate
  • +3 Kilonova?: peak M > −17, fades ≥ 0.5 mag/day within 10 d, nothing known against it
  • +2 Lens catalogue match within 5″
  • +3 glSN?: too-bright and (lens match or passive host) +2 more with a passive host
M = m − μ(z) − 2.5 log(1+z) − Aλ with Planck18 and SFD98×SF11; m = brightest real detection (else discovery mag); z = DESI host (else TNS). Score ≥ 7 hi · 3–6 mid · 0–2 lo · < 0 neg.
