Base URL

Responses are JSON (errors carry an error message), except images and the CSV of /api/query/objects.


Base: https://kinder.astro.ncu.edu.tw

Authentication

  • Public API — No key needed. Rate limited to 1 req/s per IP per endpoint.
  • Authenticated API — Pass API key via X-API-Key header or ?api_key= query param.

Object query: find transients without logging in

Search Kinder's objects the way the Transient page does (classification, redshift, discovery date, magnitudes, discoverer, position) and get a CSV or JSON table. Only object metadata is returned, never photometry or spectra. Without a key you get the public objects; add your api_key to include the restricted objects your account may open.

  1. See what you can ask for: GET /api/query lists every parameter, the classifications with how many objects each has, the sort keys and the CSV columns.
  2. Download a table: GET /api/query/objects?type=SLSN-I returns every SLSN-I as a CSV file. Combine filters with &, e.g. &z_max=0.2&discovered_after=2025-01-01.
  3. Several types: type=SLSN-I,SLSN-II; every SLSN class: type=SLSN*; unclassified: type=AT.
  4. Around a position: ra=10:00:28.6&dec=+02:12:21&radius=60 (radius in arcsec) adds separation_arcsec and sorts nearest first.
  5. More than 1000 rows: raise limit (max 10000) or page with offset; the X-Total-Count header says how many match and X-Next-Offset where the next page starts (JSON: total, next_offset).
  6. Mistakes are reported: a misspelt parameter or type returns HTTP 400 with a suggestion instead of silently returning everything.
Try it
/api/query/objects
Download CSV Open JSON
Python (pandas)
import pandas as pd url = "https://kinder.astro.ncu.edu.tw/api/query/objects" df = pd.read_csv(url + "?type=SLSN-I&z_max=0.5") print(len(df), df[["name", "redshift", "peak_abs_mag"]].head())

import requests url = "https://kinder.astro.ncu.edu.tw/api/query/objects" params = {"type": "SN Ia", "format": "json", "limit": 10000} rows, offset = [], 0 while offset is not None: page = requests.get(url, params={**params, "offset": offset}).json() rows += page["objects"] offset = page["next_offset"] print(len(rows))

GET /api/distance Luminosity distance & absolute magnitude

Calculate luminosity distance from redshift using a flat ΛCDM cosmology. Optionally compute absolute magnitude when apparent magnitude is provided. Cosmological parameters default to Planck 2018.

ParameterDescriptionDefault
zrequiredRedshift
z_erroptionalRedshift uncertainty → adds distance error to response
moptionalApparent magnitude → enables absolute magnitude output
AoptionalExtinction (magnitudes)0
H0optionalHubble constant (km/s/Mpc)67.7
Om0optionalMatter density Ωm0.309
Tcmb0optionalCMB temperature (K)2.725
Cosmology reference: Planck Collaboration 2020, A&A, 641, A6 — ADS
Example request
/api/distance?z=0.039&m=15.3&A=0.1
Example response
{ "success": true, "result": { "input": { "z": 0.039, "z_err": null, "m": 15.3, "A": 0.1 }, "cosmology": { "H0": 67.7, "Om0": 0.309, "Tcmb0": 2.725 }, "distance": { "distance_mpc": 171.23, "distance_gpc": 0.1712, "distance_pc": 171230000.0, "distance_ly": 558511800.0, "distance_km": 5.28e21, "redshift": 0.039 }, "magnitude": { "absolute_magnitude": -18.52, "distance_modulus": 36.17, "k_correction": 0.17, "distance_mpc": 171.23, "extinction": 0.1 } } }
GET /api/coords RA / DEC coordinate conversion

Convert between HMS/DMS sexagesimal and decimal degree formats. RA and DEC can be converted in the same request.

ParameterDescription
ra_hmsoptionalRA in hh:mm:ss.s → returns decimal degrees
ra_degoptionalRA in decimal ° → returns HMS
dec_dmsoptionalDEC in ±dd:mm:ss → returns decimal degrees
dec_degoptionalDEC in decimal ° → returns DMS
Provide ra_hms or ra_deg, and/or dec_dms or dec_deg. At least one parameter is required.
Example request
/api/coords?ra_hms=12:34:56.78&dec_dms=-23:45:12.34
Example response
{ "success": true, "result": { "ra_hms": "12:34:56.78", "ra_decimal": 188.73658, "dec_dms": "-23:45:12.34", "dec_decimal": -23.75343 } }

GET /api/objects/{name} Object metadata (+ photometry & spectra with key)

Returns object metadata (coordinates, redshift, type, discovery info, etc.) for anyone. Pass a valid api_key to also receive photometry and spectroscopy, filtered to only the sources your account has permission to access.

ParameterDescription
{name}pathObject name — full (AT2025wny, SN2024abc) or year+letters (2025wny)
api_keyoptionalYour API key. When valid, adds photometry and spectra arrays to the response
Without key — returns metadata only (public fields).
With key — also returns photometry[] and spectra[], each filtered to sources you have access to.
Public (no key)
/api/objects/2025wny
With API key
/api/objects/2025wny?api_key=YOUR_KEY
Python
import requests # Public (metadata only) r = requests.get("https://your-domain.com/api/objects/2025wny") # Authenticated (+ photometry + spectra) r = requests.get("https://your-domain.com/api/objects/2025wny", params={"api_key": "YOUR_KEY"}) print(r.json())

GET /api/query/objects Find objects by type, redshift, date, magnitude or position (CSV / JSON)

The Transient page's filters without logging in. Returns object metadata only (no photometry or spectra), as CSV by default. Unknown parameters and types are refused with a suggestion, so a typo never returns everything. Rate limit: 10 requests per 10 s per IP.

ParameterDescription
typeoptionalClassification, case-insensitive; several comma-separated (SLSN-I,SLSN-II); SLSN* for a prefix; AT = unclassified, Classified = all classified
nameoptionalPart of the name or an internal name (2024abc, ZTF24)
discovered_after / discovered_beforeoptionalDiscovery date range, YYYY-MM-DD (inclusive)
z_min / z_maxoptionalRedshift range
mag_min / mag_maxoptionalDiscovery magnitude range
peak_mag_min / peak_mag_maxoptionalPeak apparent magnitude range
peak_abs_mag_min / peak_abs_mag_maxoptionalPeak absolute magnitude range
discovereroptionalPart of the reporting / source group or reporters (ZTF, GOTO)
statusoptionalinbox, followup or snoozed
ra, dec, radiusoptionalCone search: centre in degrees or hh:mm:ss / ±dd:mm:ss, radius in arcsec (default 60, max 36000). Adds separation_arcsec and sorts by distance
sort, orderoptionaldiscovery_date (default), name, redshift, discovery_mag, peak_mag, peak_abs_mag, last_photometry, distance; asc / desc
limit, offsetoptionalRows per request (default 1000, max 10000) and paging; the X-Total-Count / X-Next-Offset headers tell how many match and where the next page starts
formatoptionalcsv (default) or json
api_keyoptionalAlso returns the restricted objects your account may open

Authenticated API

API Key required

How to authenticate

  • Via HTTP header: X-API-Key: your_key_here
  • Via query param: ?api_key=your_key_here
  • Generate your key from the account settings page (authorized users only).
GET /api/test Validate API key

Test whether an API key is valid. Returns the associated user information on success.

Example request
curl -H "X-API-Key: YOUR_KEY" https://kinder.astro.ncu.edu.tw/api/test
Example response
{ "success": true, "message": "API Authentication successful!", "user": { "name": "Alex Lee", "email": "user@example.com", "role": "admin", "is_admin": true, "groups": ["GREAT Lab"] } }
